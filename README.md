模组介绍
===
本模组以丰富矿物为主，添加了大量的矿石以及对应装备工具以及新的挖掘等级<br/>
所以在本模组里，你可以发现你的地下生成了非常丰富种类繁多的矿脉<br/>
ps:可能对不喜欢大量矿石来增加繁琐的人而言没那么友好
